# Letraria

Obras e formas desenhadas com letras: arte ASCII colorida e animada. Next.js + TypeScript + Tailwind.

## Páginas

- `/` — *A Noite Estrelada* (Van Gogh, 1889, domínio público) em ASCII colorido, com moldura dourada. O zoom começa no centro e se afasta até revelar a obra inteira.
- `/coracao` — um coração que se desenha em contorno e se preenche de baixo para cima com palavras de amor e carinho, em tons de vermelho.

## Rodando

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Créditos

A imagem de *A Noite Estrelada* é a reprodução do Google Art Project, em domínio público, obtida na Wikimedia Commons.
